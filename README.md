# crypto-wallet-pairs-back
Este proyecto tiene como objetivo la gestión de información relacionada con criptomonedas, permitiendo a los usuarios almacenar y consultar datos sobre sus activos criptográficos. El sistema está compuesto por varias tablas que gestionan la información del usuario, sus wallets y las criptomonedas que compran.


# Archivo .env
ACCESS_TOKEN_EXPIRE_MINUTES (Minutos de duracion del token)

SECRET_KEY (esta se puede genera en consola con ```openssl rand -hex 32```)
